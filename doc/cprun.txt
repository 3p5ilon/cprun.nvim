*cprun.txt*   Minimal C++ competitive programming compile & run workflow for Neovim

==============================================================================
CPRUN.NVIM                                                        *cprun*

Minimal, fast C++ compile & run plugin for competitive programming in Neovim.

FEATURES                                                  *cprun-features*

- Toggle split layout (`inp` | `out`) beside the code pane.
- Auto-creates `inp` and `out` files if missing; auto-saves on edit.
- Fast interactive terminal run (`g++ -O2`).
- Warning build (`-Wall -Wextra -Wshadow -O2`) via `< inp > out`.
- AddressSanitizer build (`clang++ -fsanitize=address`) via `< inp > out`.
- Execution time shown as `42ms` or `1.85s`.

==============================================================================
CONFIGURATION                                              *cprun-config*

To configure cprun.nvim, call `setup()` in your Neovim configuration: >lua

    require("cprun").setup({
      compiler = "g++",           -- Default C++ compiler
      asan_compiler = "clang++",  -- AddressSanitizer compiler
      cpp_std = "c++17",          -- C++ language standard
      flags = { "-Wall", "-Wextra", "-Wshadow", "-O2" },
      fast_flags = { "-O2" },
      asan_flags = { "-Wall", "-Wextra", "-Wshadow", "-fsanitize=address", "-O2" },
      term_height = 12,           -- Bottom terminal height for run_fast
      layout_width = 0.35,        -- Split ratio for input/output panes
      input_file = "inp",         -- Name of input file
      output_file = "out",        -- Name of output file
      auto_create_files = true,   -- Auto create inp/out if missing
      auto_save = true,           -- Auto save inp/out on change
      keymaps = {
        enable = true,
        toggle_layout = "<leader>cp",
        run_fast = "<F6>",
        run_asan = "<F7>",
        run_warnings = "<F8>",
      },
    })
<

==============================================================================
COMMANDS                                                   *cprun-commands*

:CPToggle                                                         *:CPToggle*
    Toggle the input/output split layout next to the code pane.

:CPRunFast                                                     *:CPRunFast*
    Save buffers, cd to file dir, compile with fast flags and open an
    interactive bottom terminal split.

:CPRunWarnings                                             *:CPRunWarnings*
    Save buffers, cd to file dir, compile with warnings, and run redirecting
    input -> stdin and stdout -> output file.

:CPRunAsan                                                     *:CPRunAsan*
    Save buffers, cd to file dir, compile with AddressSanitizer using
    asan_compiler, and run redirecting input -> stdin and stdout -> output file.

==============================================================================
KEYMAPS                                                     *cprun-keymaps*

Default buffer-local keymaps for `cpp` filetypes:

Keymap             Mode            Description
------------------ --------------- ------------------------------------
<leader>cp         Normal          Toggle inp / out layout
<F6>               Normal, Insert  Fast compile & interactive terminal
<F7>               Normal, Insert  AddressSanitizer build (clang++)
<F8>               Normal, Insert  Warning build (g++)
